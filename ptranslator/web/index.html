Persian Book Translator

Translate books, documents and subtitles into Persian (فارسی) with your own API providers, all working in parallel.

1. Your API providers

OnNameBase URLAPI keyModelParallelUse for

Any OpenAI-compatible API works. Base URL is the part before /chat/completions, e.g. https://api.example.com/v1. "Parallel" = how many requests that provider handles at once (1 is safe for free tiers). Everything is saved in this browser only.
Backup keys: put several keys in one API key box, separated by commas. If a key is rate limited, rejected or runs out of quota/credits, the next key takes over automatically. Use for: click Translate / Review on each provider to choose which job it works on (both lit = both jobs). A translate job only uses providers with Translate on; a review (refine) job only uses providers with Review on. Use the buttons above the table to set every provider at once.
You can also add providers or keys while a translation is running: edit this table, then press Add to running job below.
