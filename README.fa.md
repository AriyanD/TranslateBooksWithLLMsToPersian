# مترجم کتاب فارسی (Persian Book Translator)

ترجمهٔ **EPUB، DOCX، PDF، TXT/MD و SRT** (یا **متن چسبانده‌شده**) به **فارسی** با **API های خودتان**؛ همهٔ providerها **هم‌زمان** روی یک کتاب کار می‌کنند. مدل لوکال ندارد؛ با هر سرویسی که فرمت OpenAI (`/chat/completions`) را بفهمد کار می‌کند (Gemini، Groq، OpenRouter، Mistral، NVIDIA NIM، DeepSeek و ...).

## اجرا (ساده‌ترین راه)
1. از بخش **Releases** همین مخزن، فایل zip سیستم‌تان را بگیرید (Windows / macOS / Linux) و از حالت فشرده خارج کنید.
2. روی `PersianBookTranslator` دوبار کلیک کنید. مرورگر روی `http://127.0.0.1:7860` باز می‌شود. **پنجرهٔ مشکی را باز نگه دارید** (بستنش برنامه را می‌بندد).
3. ویندوز ممکن است هشدار SmartScreen بدهد (برنامه امضای دیجیتال ندارد): **More info ← Run anyway**. در مک: راست‌کلیک ← Open.

## کار با برنامه
1. **مرحلهٔ ۱ – Providerها:** برای هر سرویس نام (دلخواه و یکتا)، Base URL (مثلاً `https://api.example.com/v1`)، کلید API و نام مدل را وارد کنید. دکمهٔ **Models** فهرست مدل‌ها را می‌آورد و **Test** سالم بودن همهٔ کلیدها را بررسی می‌کند.
   * **Parallel:** تعداد درخواست هم‌زمان به آن سرویس. برای پلن‌های رایگان سخت‌گیر عدد ۱ بگذارید.
   * **Use for:** سرویس برای **ترجمه**، **بازبینی (Review)** یا هر دو.
   * چند کلید پشتیبان: `key1, key2, key3` در یک کادر. کلیدی که محدودیت یا اتمام سهمیه بخورد خودکار کنار می‌رود.
2. **مرحلهٔ ۲ – فایل:** کتاب را بکشید و رها کنید. برای ترجمهٔ سریع‌تر تعداد providerها را بیشتر کنید.
3. **شروع:** پیشرفت، زمان باقی‌مانده و پنجرهٔ «آخرین بخش ترجمه‌شده» (متن اصلی کنار فارسی) نمایش داده می‌شود.
4. **دانلود:** خروجی با نام `mybook.fa.epub` (راست‌به‌چپ) ذخیره می‌شود.

### PDF و متن چسبانده‌شده
* **PDF:** متن صفحه‌به‌صفحه استخراج می‌شود، خطوط شکسته به پاراگراف برمی‌گردند، سرصفحه/پاصفحهٔ تکراری حذف می‌شود و خروجی یک فایل `mybook.fa.docx` راست‌به‌چپ است. (نوشتن فارسی داخل خودِ PDF حروف را خراب می‌کند؛ در Word گزینهٔ «Save as PDF» را بزنید.) PDFهای اسکن‌شده اول باید OCR شوند.
* **تب «✍️ Paste text»:** متن را بچسبانید، ترجمه یا بازبینی کنید، فارسی را کپی کنید یا به‌صورت `.txt` ذخیره کنید.

### نکته‌ها
* اگر برنامه بسته شد یا قطع شد، **همان فایل را دوباره بدهید**؛ از جایی که مانده ادامه می‌دهد. پیشرفت در پوشهٔ `PersianBookTranslator_Data` کنار برنامه ذخیره می‌شود.
* اگر همهٔ کلیدها تمام شوند، کار **متوقف می‌شود (waiting)** و چیزی از بین نمی‌رود. می‌توانید در حین اجرا کلید/provider جدید اضافه کنید (**+ Add to running job**).
* **حالت بازبینی (Refine):** فایلی که قبلاً به فارسی ترجمه شده را در «Drop files to refine» بیندازید تا ویرایش ادبی شود. خروجی: `mybook.refined.fa.epub`.
* اندازهٔ هر درخواست: ۱۵۰۰ تا ۳۰۰۰ نویسه برای سرویس‌های رایگان مناسب است.
* کلیدها فقط در مرورگر شما (localStorage) می‌مانند و روی دیسک ذخیره نمی‌شوند. مرورگر آن‌ها را برای هر آدرس جدا نگه می‌دارد؛ برای انتقال بین `localhost` و `127.0.0.1` از **Export JSON** و **Import JSON** استفاده کنید.

### خط فرمان
```bash
pip install -r requirements.txt
cp providers.example.json providers.json    # و کلیدها را پر کنید
python translate.py mybook.epub -p providers.json
```
گزینه‌ها: `--chunk-chars 2500`، `--instructions "لحن رسمی"`، `--persian-digits`، `--refine`، `--no-wait`، `--no-resume`.
